# SeeMath 📐✨

**SeeMath** — это локальное приложение для красивого оформления, пошагового решения и сохранения математических уравнений. Оно доступно как в виде **веб-сайта** (в браузере), так и в виде **нативного десктопного приложения** на Python. Программа превращает ваш простой текст (дроби, корни, степени) в идеальные математические формулы, как в учебнике.

Ссылка на репозиторий: [https://github.com/thethaaat-git/seemath/](https://github.com/thethaaat-git/seemath/)

---

## 🚀 Основные возможности

- **Режим сайта и приложения:** Запускается как в браузере на `localhost`, так и в отдельном нативном окне (через `tkinter`).
- **Умный выбор порта:** Если порт `1234` занят, приложение автоматически попробует запуститься на `4321`, `1111`, `0000` или `8888`.
- **Красивый рендеринг формул:** Благодаря библиотеке **KaTeX**, все дроби, корни и степени выглядят идеально ровно.
- **Альтернативные пути решения:** Если задачу можно решить разными способами, вы можете создать «Развилку» и переключаться между вариантами решения с помощью удобных кнопок.
- **Умный парсер текста:** Пишите формулы простым текстом (`1/2`, `√(25/16)`), а программа сама расставит математические знаки.
- **Две темы оформления:** Светлая (солнце ☀️) и тёмная (луна 🌙) для комфортной работы.
- **Выезжающая панель:** Боковое меню можно скрыть одной кнопкой, чтобы освободить место для чтения решений.
- **Локальное сохранение:** Все ваши уравнения сохраняются в файл `lib.json` прямо на вашем компьютере.

## 🛠️ Как скачать и запустить

Для работы приложения вам понадобится установленный **Python** (версия 3.8 или выше).

1. **Скачайте проект:**
   Откройте терминал (командную строку) и склонируйте репозиторий:

   ```bash
   git clone https://github.com/thethaaat-git/seemath.git
   ```

   _(Или просто скачайте ZIP-архив с GitHub и распакуйте его)._

2. **Перейдите в папку с проектом:**

   ```bash
   cd seemath
   ```

3. **Установите необходимые библиотеки:**
   Для запуска нативного десктопного приложения (с идеальным рендерингом, как в браузере) используется библиотека `pywebview`. Установите её командой:

   ```bash
   pip install pywebview
   ```

   _(Или, с помощью файла `requirements.txt`: `pip install -r requirements.txt`)_

4. **Запустите приложение:**

   ```bash
   python main.py
   ```

5. **Как это работает:**
   После запуска скрипта **автоматически откроется десктопное окно** программы.
   Одновременно с этим в фоновом режиме запустится локальный сервер. Если вы хотите открыть приложение в браузере (например, чтобы использовать расширения), в консоли будет выведена ссылка (например: `http://localhost:1234/web/`).
   Если порт `1234` занят другой программой, SeeMath сам найдет свободный порт.

## 📖 Как пользоваться

1. **Создание уравнения:** Нажмите кнопку **«+ Новое уравнение»** в левом меню. Введите название.
2. **Добавление действий:** Нажмите **«+ Обычный шаг»**, чтобы добавить действие ①, ② и т.д.
3. **Написание формул:** В строке ввода используйте панель инструментов или пишите вручную по правилам (см. ниже).
4. **Сохранение:** Нажмите **«Сохранить в lib.json»**, чтобы уравнение осталось в памяти программы.

### 📝 Синтаксис для ввода формул (Шпаргалка)

Программа понимает обычный текст, но превращает его в математику:

| Что вы пишете | Как это выглядит на экране       | Описание                                                       |
| :------------ | :------------------------------- | :------------------------------------------------------------- |
| `1/2`         | \(\frac{1}{2}\)                  | Обычная дробь                                                  |
| `1_9/16`      | \(1\frac{9}{16}\)                | Смешанная дробь (целая часть_числитель/знаменатель)            |
| `√(25/16)`    | \(\sqrt{\frac{25}{16}}\)         | Корень (внутри скобок может быть что угодно)                   |
| `(1*5)/(5*4)` | \(\frac{1 \cdot 5}{5 \cdot 4}\)  | Дробь, где числитель и знаменатель в скобках                   |
| `(1/2)^2`     | \(\left(\frac{1}{2}\right)^{2}\) | Степень для всей дроби (обязательно используйте скобки)        |
| `*`           | \(\cdot\)                        | Знак умножения                                                 |
| `:`           | \(\div\)                         | Знак деления (после русских букв останется обычным двоеточием) |

### 🔀 Разные пути решения

Если в середине решения задачу можно решить по-разному:

1. Нажмите **«+ Развилка решений»**.
2. Внутри появятся «Путь 1» и «Путь 2». Добавьте шаги в каждый из них.
3. На главном экране появятся кнопки, переключаясь между которыми, вы сможете показывать разные варианты решения.

### 📜 Правила и свойства

В выпадающем списке слева от строки ввода можно выбрать:

- **Действие (обычное):** для математики.
- **Правило, свойство, формула (курсив):** для текста. Весь текст и формулы будут написаны курсивом, что удобно для выделения правил вроде _«Свойство кв. корня: √a _ √b = √(a*b)»*.
